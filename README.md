# ☕ Old Velvet Cafe

A modern, responsive café website designed for **Old Velvet Cafe, Bhagalpur, Bihar**. The website features a warm beige and coffee-brown aesthetic with subtle animations, interactive menu cards, a gallery, testimonials, contact section, and responsive layouts.

## 📍 About the Cafe

**Old Velvet Cafe** is a rooftop coffee café located in Bhagalpur, Bihar.

📍 **Address:** MG Rd, MG Path, Bose Park, Domino's, Bhagalpur, Bihar 812001

🕐 **Opening Hours:**
Open until 10:00 PM

💰 **Price Range:** ₹200–₹400 per person

The café specializes in coffee, bakery items, snacks, sandwiches, burgers, tea, and desserts.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/old-velvet-cafe.git
```

### 2. Open the project

```bash
cd old-velvet-cafe
```

### 3. Run the website

Open `index.html` in your browser.

For development, you can also use **Live Server** in VS Code.
